ECONOMIC MACHINE MONITOR — running it on your own computer
===========================================================

What this is
  A dashboard of the business cycles of 13 major economies and the world.
  It collects its own data from public sources (IMF, World Bank, central
  banks, stock exchanges, news) and updates itself every hour while it runs.

What you need
  Python 3.9 or newer. Nothing else to install.
    Mac:      usually already there. If not: https://www.python.org/downloads/
    Windows:  https://www.python.org/downloads/  (tick "Add python.exe to PATH")
  An internet connection, so it can fetch data.

How to start it
  Mac:      double-click  "Economic Dashboard"  (the app with the wave icon, in
            this folder). Drag it to the Dock to keep it handy, but leave the
            app itself in this folder.
            First time only, if this copy came from the internet (Google
            Drive, email, AirDrop): macOS says it cannot check the app. Click
            Done, open System Settings > Privacy & Security, scroll down, click
            "Open Anyway" next to Economic Dashboard and confirm. A copy from
            a USB stick opens straight away.
  Windows:  double-click  "Start Dashboard (Windows).bat"  once. It puts an
            "Economic Dashboard" icon on your desktop; from then on use that.
            If Windows shows a blue warning, click "More info", then "Run anyway".
  Linux, or from a terminal anywhere:   python3 run_local.py

  Your browser opens the dashboard at http://localhost:8765 . No window stays
  open when you start it from the icon. Double-clicking the icon again while it
  is running just opens the page again. The numbers shown at first are the
  ones saved last time; a refresh starts straight away and the page updates by
  itself when it finishes (under a minute; about 4 minutes once a day when the
  slower economic data is due). While it runs it refreshes every hour.

  Prefer a window that shows what it is doing? On a Mac, double-click
  "Start Dashboard (Mac).command" instead.

How to stop it
  Started from the icon: just close the dashboard tab. It stops by itself 30
  minutes after the last dashboard tab is closed. A record of what it did is
  in local.log in this folder.
  Started from a start file or a terminal: close that window, or press Ctrl+C.

Ask AI
  Every country page, the World page and the Compare page have an "Ask AI" box.
  - "Copy for Claude or ChatGPT" copies the page's figures and your question.
    Paste it into the Claude or ChatGPT app. Works with any account.
  - "Ask Claude" appears if Claude Code is on this computer: either the
    Claude desktop app (Mac or Windows) or Claude Code installed on its own
    (https://claude.com/claude-code), signed in. The answer then shows on the
    page. It always uses Claude's Opus model and your Claude subscription;
    no API key is needed.
  AI answers are a reading of the data, not investment advice.

Changing it
  Open this folder in Claude Code and say what you want changed. The file
  CLAUDE.md tells Claude how the project is laid out. README.md has a table
  of the common edits (add a country, change a rule, change a source).

Good to know
  - Only your own computer can open the dashboard. Nothing is uploaded.
  - If a data source is down, the last good value stays and a warning shows
    under "How it works" > Data health.
  - It is an educational tool. The signals are mechanical rules over public
    data, not investment advice.
